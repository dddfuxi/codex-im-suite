## 安全与失败关闭

- API Key 只进入本机 `config.env` 的受控 secret 字段，面板只展示 set/masked；不得写入仓库、日志、卡片或审计正文。
- `off`、缺少密钥、超时、取消、HTTP 错误或非法返回均不得伪造概率；纯模式允许显式的受限 planner 先生成题目，但 planner 或 Jev 失败都必须失败关闭，不得回落静态分类或把 planner 文本伪装成 Jev 概率。
- Jev `choice` 是模型分类结果，不复用真人点击的 `ChoicePromptRegistry` 或 `choice-card`。
- 纯模式开关仅影响当前群；群禁用、allowlist、机器人自消息和 bot-to-bot 门禁继续优先。
- “接入完成后私聊通知”只在真实 API、Runtime、Bridge、Feishu 卡片和重启后消息回执均通过时执行，并绑定本轮真实发起人。
