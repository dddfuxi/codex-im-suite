# 统一计划任务 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本仓库未收到用户派生 subagent 的授权，禁止改用 subagent-driven-development。

**Goal:** 建立参考 OpenClaw 可靠性原则、兼容飞书、支持固定通知与动态 Agent turn 的统一计划任务系统，并把现有单次 reminder 平滑迁移到同一运行时能力。

**Architecture:** `bridge-runtime` 提供可替换存储、时间计算、调度、执行、重试和恢复；`bridge-core` 只负责结构化动作、权限、飞书证据与交付呈现；控制面板通过 CLI/Control API 管理任务；Skill 只指导意图理解和受控 Host 调用。任务数据写入 `CTI_HOME/data/scheduled-tasks`，不得进入工作区或记忆仓库。

**Tech Stack:** TypeScript、Node.js 20、`node:test`、Croner、原子 JSON 文件、现有 Bridge Host/LLM/Feishu delivery、React 控制面板、C# Control API、Codex Skill。

`schedule.ts` 使用 Croner，并保持所有返回值为 ISO 字符串：

```ts
import { Cron } from 'croner';
import type { ScheduledTaskSchedule } from './types.js';

function assertTimezone(timezone: string): void {
  new Intl.DateTimeFormat('en-US', { timeZone: timezone }).format(new Date(0));
}

export function normalizeScheduledTaskSchedule(input: ScheduledTaskSchedule): ScheduledTaskSchedule {
  if (input.kind === 'every') {
    if (!Number.isFinite(input.everyMs) || input.everyMs < 1_000) throw new Error('固定间隔必须至少 1 秒');
    if (!Number.isFinite(new Date(input.anchorAt).getTime())) throw new Error(`无效锚点：${input.anchorAt}`);
    return { ...input, everyMs: Math.floor(input.everyMs), anchorAt: new Date(input.anchorAt).toISOString() };
  }
  assertTimezone(input.timezone);
  if (input.kind === 'at') {
    const at = new Date(input.at);
    if (!Number.isFinite(at.getTime())) throw new Error(`无效单次时间：${input.at}`);
    return { ...input, at: at.toISOString() };
  }
  new Cron(input.expression, { timezone: input.timezone, catch: false });
  return { ...input, expression: input.expression.trim() };
}

export function computeNextScheduledAt(schedule: ScheduledTaskSchedule, after: string): string | undefined {
  const afterMs = new Date(after).getTime();
  if (!Number.isFinite(afterMs)) throw new Error(`无效参考时间：${after}`);
  if (schedule.kind === 'at') {
    const atMs = new Date(schedule.at).getTime();
    return atMs > afterMs ? new Date(atMs).toISOString() : undefined;
  }
  if (schedule.kind === 'every') {
    const anchorMs = new Date(schedule.anchorAt).getTime();
    const steps = Math.floor(Math.max(0, afterMs - anchorMs) / schedule.everyMs) + 1;
    return new Date(anchorMs + steps * schedule.everyMs).toISOString();
  }
  assertTimezone(schedule.timezone);
  return new Cron(schedule.expression, { timezone: schedule.timezone, catch: false })
    .nextRun(new Date(afterMs))?.toISOString();
}
```
