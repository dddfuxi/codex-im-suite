# 记忆候选与归档中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把普通对话产生的暂定印象移出主知识索引，并提供已确认、候选、已归档三层记忆生命周期以及可恢复、可审计的控制面板入口。

**Architecture:** Runtime 负责 managed memory state、候选资格、归档存储、迁移和索引；控制面板只通过独立 CLI Gateway 调用，不直接编辑 Markdown。主索引只消费 confirmed，candidate 和 archive 使用独立读取协议；旧 `tentative` 通过 dry-run 迁移保留为 candidate。

**Tech Stack:** TypeScript/Node.js 20、Node test runner、C# .NET 9、React 19/Vite、UTF-8 Markdown/JSON、原子文件写入。

```ts
export function readManagedMemoryDocument(filePath: string): ManagedMemoryDocument {
  const content = fs.existsSync(filePath) ? fs.readFileSync(filePath, 'utf8') : '';
  const decoded = decodeManagedState(content);
  return { filePath, content, state: upgradeManagedState(decoded), baseHash: sha256(content) };
}

export function writeManagedMemoryDocument(
  document: ManagedMemoryDocument,
  expectedBaseHash: string,
): void {
  const current = fs.existsSync(document.filePath) ? fs.readFileSync(document.filePath, 'utf8') : '';
  if (sha256(current) !== expectedBaseHash) throw new Error('managed memory source changed; refresh required');
  atomicWrite(document.filePath, renderManagedMemoryDocument(document));
}
```
