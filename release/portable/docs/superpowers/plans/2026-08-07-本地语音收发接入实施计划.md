# Qwen3-TTS 本地语音模型接入实施计划

> 日期：2026-08-08
> 范围：`codex-im-suite` 开发版，飞书首发
> 版本目标：`0.4.0`

## 目标与边界

- 飞书语音入站由本地 ASR 转写后再交给 Primary Agent；原始音频不冒充当前 Provider 已支持的原生音频输入。
- 收到真实飞书语音后默认用语音回复；`/voice on` 开启会话语音，`/voice off` 在再次开启前硬性禁用所有语音回复；普通文字默认仍返回文字。
- 用户明确要求语音时，Agent 只能通过受限 `cti-final.speech.mode=voice_only` 声明呈现意图，不能指定模型、路径、音色 ID、命令、`file_key` 或平台身份。Bridge 不用自然语言关键词正则作为授权或完成门禁。
- 默认 TTS 为 `Qwen3-TTS-12Hz-1.7B-CustomVoice + Serena`；低显存显式回退为 `0.6B-CustomVoice`，授权复刻只使用对应 `1.7B/0.6B-Base`。
- 语音成功时只保留一个飞书原生语音终态；合成、验证、进度卡关闭或上传任一步失败时，只发送一次完整文字。
- 明确唱歌请求必须走独立 ACE-Step 1.5 `SingingHost`；普通 TTS 不得冒充歌声。面板分别选择和试听说话/歌声音色。
- 首期只改飞书。微信继续优先使用平台转写，不改变现有行为。
- 不迁移、不读取、不依赖 `F:\unity\ST4\.cti-audio`；模型、FFmpeg、Python 环境和参考音频不进入 Git、工作区、live skill 或 release 包。

## 架构落点

### Bridge Core

- [x] 声明可选 `SpeechHost`、`cti-speech-transcript/v1` 和受管合成产物回执。
- [x] 在 `prepareForAgent()` 完成后、Primary Agent 启动前处理飞书音频。
- [x] 纯语音使用可靠转写作为有效正文；文字加语音保留附言并加入带来源 ID 的结构化证据。
- [x] 空转写、无声、格式错误、超限或超时不启动 Primary，返回可行动错误。
- [x] 删除纯音频误走“用户发送了一张图片”的默认 Prompt 路线。
- [x] 新增平台无关 `sendLocalAudio()`，飞书实现原生 `file_type=opus + msg_type=audio`。
- [x] 建立 `/voice on|off` 会话策略和受限 `cti-final.speech` 清洗；移除自然语言 voice/text 关键词正则，Primary 结构化意图再由 Bridge 结合 evidence、角色与风险裁决。
- [x] 当前消息语音可成为本轮正文；原生回复旧语音只作为上下文，不把旧录音中的命令提升为当前授权。
- [x] 合成前由 Runtime 签发 `modelId + revision + voiceProfileId`，Core 对请求与回执逐项绑定。
- [x] 保证语音与文字只有一个用户可见终态，并在 Store/outbound ref 保留最终文字与真实语音消息 ID。
- [x] 新增受限 `cti-final.singing`、独立 `SingingHost` 和唯一歌声/文字终态，拒绝模型提供 provider、路径、音色 ID、URL、token、命令或平台身份。

### Runtime 与本地 sidecar

- [x] 实现 `CTI_SPEECH_*` / `CTI_SINGING_*` 配置解析、保存和启动覆盖。
- [x] 实现显式配置 → `CTI_HOME\runtime-deps` → PATH 的依赖解析；显式坏路径失败关闭。
- [x] 使用参数数组调用 FFmpeg/ffprobe，完成真实文件头、格式、时长、大小和非符号链接校验。
- [x] 实现只监听 `127.0.0.1`、使用进程临时令牌的版本化语音 sidecar 协议。
- [x] ASR 保持 SenseVoiceSmall GGUF Q8 CPU；TTS 默认改为 Qwen3-TTS 1.7B CustomVoice + Serena，支持 0.6B CustomVoice 和两种 Base 克隆模型。
- [x] 受管依赖 manifest 升级为兼容 v1 的 v2 文件集合：四个 Qwen 模型固定官方 revision、逐文件 SHA-256/大小/相对路径，完整 stage 校验后原子发布，失败保留旧版本。
- [x] Qwen Sidecar 强制离线本地目录、CUDA、BF16/FP16、Windows SDPA、单并发，并返回真实 Provider/模型/revision/峰值显存；OOM 返回稳定诊断码。

- [x] 实现音色注册表：授权确认、相对路径、SHA-256、参考转写、来源与许可证。
- [x] 运行状态仅暴露 `ready / optional_missing / blocked / error`、能力和稳定诊断码。
- [x] 实现 ACE-Step 1.5 loopback API 客户端、Bearer token、禁止重定向、benchmark 门禁以及 Ogg/Opus/Hash 产物校验。
