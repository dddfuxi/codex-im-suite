# 平台证据与操作边界

## 1. 能力入口选择

每次实时查询先检查当前工具目录，不按名称假设能力已经安装。可用入口按可信度排序：

1. 美团/大众点评官方或已授权合作接口：使用工具返回的商家、菜单、价格和订单字段，并保留返回时间。
2. 已登录浏览器或手机 App：先核对当前域名、App、账号作用域和位置，再读取可见页面；不要索取或导出登录凭据。
3. 限定官方域名的联网检索：只用于发现公开商家页和公开点评摘要，不据此声称实时库存、配送或优惠。
4. 用户提供的链接或截图：记录平台、页面时间和可见范围；截图外字段保持未知。

若工具、登录态或页面不可用，退回通用餐饮建议，不构造平台数据。

## 2. 平台职责

### 美团 / 美团外卖

优先用于当前外卖商家、菜单、规格、配送费、起送价、预计送达、优惠和购物车。只有当前页面或授权接口明确展示的值才算实时证据。

### 大众点评

优先用于到店餐厅、菜品口碑、环境/服务反馈和公开用户评价。点评内容具有主观性；区分平台事实、用户评价和 Agent 总结，不把单条评论写成确定事实。

### 跨平台

- 仅在名称和地址/门店标识同时匹配时合并同店信息。
- 不直接比较不同平台的评分数字或热度排名。
- 同一字段冲突时并列显示来源与查询时间，不擅自选择较好看的值。
- 外卖门店与到店门店可能不是同一营业主体，默认分开处理。

## 3. 最小证据记录

每个候选至少保留：

- `platform`：meituan、meituan-waimai、dianping 或其他真实来源；
- `merchant_name`：页面可见原名；
- `location_scope`：城市/商圈/用户授权位置范围，不记录完整住址；
- `observed_at`：北京时间查询时间；
- `source_kind`：partner_api、interactive_browser、mobile_app、official_web_search、user_link 或 user_screenshot；
- `observed_fields`：本次实际看到的价格、评分、距离、配送等字段；
- `unknowns`：对决策重要但未核实的字段。

不要把搜索摘要、模型正文或旧会话记忆升级为新的实时证据。

## 4. 浏览器/App 操作

1. 操作前核对目标确实是用户指定的美团或大众点评页面/App。
2. 搜索和筛选属于低风险只读操作，可在已授权会话内主动执行。
3. 加购物车属于可撤销副作用，仅在用户选定商家和菜品后执行，并立即回读购物车。
4. 提交订单属于金融副作用，必须遵循 SKILL.md 的新鲜摘要与显式确认门禁。
5. 遇到登录、验证码、支付或身份验证立即暂停并让用户接管。
6. 页面结构变化、按钮含义不清或价格刷新时停止，重新读取页面，不靠坐标记忆继续点击。

## 5. 不可用与失败

- 官方接口无权限：说明需要合作方资质或授权，不改用私有接口。
- 浏览器未登录：允许用户自行登录后继续，不要求发送账号密码。
- 反爬/验证码：停止自动化，不绕过。
- 商家页失效或异地：丢弃该候选并重新检索。
- 下单点击后无回执：报告“结果未确认”，回读订单列表；不得重复提交，除非确认上一请求未创建订单且用户重新授权。
